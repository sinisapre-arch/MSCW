# Landscape portfolio mirror

Offline copy of [portfolio-qyh8lm.manus.space](https://portfolio-qyh8lm.manus.space/).

## Contents

- `index.html` — full single-page site (HTML, CSS, JS, EN/SR/RU translations)
- `IMG_3082-topaz-face-upscale-2x.jpg` — hero background
- `images/` — project galleries (Djursholm, Värmdö, Stallarholmen, Dalarö, Crimea, Ruza, Eco-hotel)
- `download-assets.ps1` — re-download script if you refresh from the live site

Manus editor scripts were removed so the site runs standalone.

## View locally

With the project dev server running:

```text
http://127.0.0.1:5180/portfolio/
```

Or open `portfolio/index.html` directly in a browser (some features work best via HTTP).
